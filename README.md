# Meus Links Mercado Livre

Este projeto é uma página simples que reúne meus links do Mercado Livre em um só lugar.  
A ideia é facilitar o acesso e organização dos produtos que vendo ou acompanho.

## 🚀 Funcionalidades
- Lista de links personalizados para produtos do Mercado Livre
- Página inicial (`index.html`) simples e direta
- Arquivo de verificação do Google para integração com serviços externos
